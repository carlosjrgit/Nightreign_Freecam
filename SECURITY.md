# Security Policy

## Supported Versions

This project is tailored specifically for the following versions of *ELDEN RING: NIGHTREIGN*:

| Version | Supported          |
| ------- | ------------------ |
| 1.3.3.0 | :white_check_mark: |
| 1.3.2.0 | :white_check_mark: |
| < 1.3.2.0 | :x:              |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository:
1. Please do not open a public issue with sensitive security details or potential exploits.
2. Submit a report privately using [GitHub Private Vulnerability Reporting](https://github.com/carlosjrgit/Nightreign_Freecam/security/advisories/new) if available.
3. Include detailed steps to reproduce the issue and the affected environment.

We aim to acknowledge and address all valid security concerns promptly.
